# SeqPanel · 60 秒产品宣传视频 · 分镜脚本（v3，含质检修复）

> 参考互联网大厂产品宣发片节奏：**痛点钩子 → 产品揭示 → 三段核心能力实机演示 → 特性快切 → 尾板**
> 全片 1920×1080 / 30fps / 60.0s（1800 帧），无实拍，界面演示基于真实产品布局与真实文案重构。

## 基本参数

| 项 | 值 |
|---|---|
| 时长 | 60.0 s |
| 分辨率 | 1920 × 1080，30 fps，H.264 High + AAC |
| 主色 | 深空黑 `#0B0F14` / 面板灰 `#161B22` / 品牌蓝 `#3B82F6` / 强调青 `#2DD4BF` |
| 字体 | 中文 微软雅黑 UI；等宽 Consolas（命令行、代码、结果） |
| 声音 | 科技感 BGM（铺底→推进→riser→收尾）+ 转场 + click / tick / typing 音效；全部谐波合成，不用宽带噪声（避免嘶嘶的"蒸汽感"） |
| 字幕 | 画面内中文主字幕 + 英文副字幕；不另配字幕文件，无旁白（音乐驱动，贴近工具类宣发主流做法） |

## 逐镜脚本

### S1 · 钩子：命令行很强，驱动很累（0.0 – 6.0s）

- **画面**：一台按内容高度收拢的终端卡片淡入（带外发光与蓝色描边，避免整段读作黑屏）。
  先给出两行真实回滚历史 —— `goalign clean seqs --input demo.fasta` 与
  `Error: unknown flag: --input`；随后逐字符敲出
  `goalign clean sites --align demo.fasta --cutoff 0 | goalign stats --phylip`，
  弹出 `[Error] in cmd/clean.go (line 87), message: fasta file should start with a >`；
  第二条 `goalign stats --phylip "demo alignment.fasta"` 因带空格路径而失败。
  右侧计数器从 `0` 滚到 `76 个可执行命令 / 42 个顶层命令组`。
- **字幕**：`进化生物学的命令行工具，很强。` → `但手工驱动它，很累。`
- **动效**：打字机 + 光标；两条报错行各闪一次红色底纹；计数器滚入。
- **声音**：随字符的敲击音、两次错误低频 thud、BGM 低音铺底。

### S2 · 痛点三连快切（6.0 – 11.0s）

- **画面**：三张卡片依次快速切入（每张约 1.6s，之间 0.2s whoosh 转场）：
  1. `输入开关，不叫 --input` —— 多数命令的输入开关是 `--align`；
  2. `格式必须真正对上` —— `--phylip / --nexus / --clustal / --stockholm`，选错即报错；
  3. `谁传递比对，谁消费比对` —— `clean seqs | stats | draw png ✗`，
     统计表是终止步，再接命令等于把表格喂给等着读 FASTA 的程序。
- **字幕**：`76 个命令，42 个命令组，每一条都要背。`
- **动效**：卡片带轻微 3D 透视入场，命中项高亮划线。
- **声音**：三次 whoosh + 每次入场的短促打击。

### S3 · 产品揭示（11.0 – 16.0s）

- **画面**：黑场收束成一条水平光带（10.55s 起，与 S2 末卡交叠以消除死场），
  配地平线光晕与沿带飞散的火花；品牌渐变背景中 `SeqPanel` 字标逐字弹入（spring），
  下方细线展开出副标题。
- **字幕**：`SeqPanel` / `面向 cobra 命令行工具的 Windows 图形操作面板`
- **动效**：光带 sweep、火花、字标 spring 缩放、背景渐变呼吸。
- **声音**：短 riser → 字标落点小打击 → 长 riser → 16.0s 大打击进入演示。

### S4 · 核心能力一：界面是反射生成的（16.0 – 27.0s）

- **画面**：真实布局的应用窗口以透视→正视飞入并放大占满画面（三列：命令表 / 输入与参数 / 工作流与结果，
  顶栏含可执行文件框、预设工作流、语言、主题）。
  1. 状态栏先显示 `反射中 · 正在解析 goalign --help · N/76 个可执行命令`，
     左列命令树在 16.9–20.8s **逐条流入**（30 行，右侧带 `--help` 首行说明，
     超宽按列宽截断加 `…`，与真实界面一致）；完成后落定为
     `GoAlign · v0.4.1 · 76 个可执行命令 / 42 个顶层命令组 · 命令表来自缓存`；
  2. 搜索框自动敲入 `clean`，命令树实时过滤，未命中项淡出；
  3. 鼠标点击 `clean sites` → 中列弹出**带类型的参数表单**：`--char string`、`--cutoff int`、
     `--count-gap bool`（已勾选）、`--preserve-order bool`、`--reference string` + 「浏览…」；
     同时该命令按真实行为**追加进右列工作流**，等价命令行同步写出；
  4. 「通用参数 (21)」折叠条展开一下再收起。
- **字幕**：`整棵命令树，从 --help 反射出来` → `每条命令，一张带类型校验的表单` → `上游升级，面板不用改代码`
- **声音**：入列 tick、搜索敲击、click（点击命令）、展开的 whoosh。

### S5 · 核心能力二：真实的操作系统管道（27.0 – 38.0s）

- **画面**：镜头推到右列「工作流」。
  **第一拍**：点顶栏预设「去缺口后统计」整体替换链条，三步依次叠加
  `1 clean seqs` → `2 clean sites --char GAP --cutoff 0` → `3 stats`；
  步骤之间画出管道，流动光点穿过 `stdout → stdin`，标注 `中间结果从不落到磁盘`。
  点「运行」→ `运行中 · 3 步 · 正在启动子进程…` → `完成 · 3 步 · 86 ms`，
  结果区揭示三个绿色步骤行与内嵌统计表（length / nseqs / avgalleles / variable sites /
  char-nb-freq / alphabet）。
  **第二拍**：`stats` 是终止步，图形来自另一条单步链 —— 点预设「比对热图」替换为
  `1 draw png`，运行后 `完成 · 1 步 · 12 ms`，内嵌显示 `draw png` 的比对热图
  （一行一条序列、一个位点一个像素，8×60，数据取自 `samples/demo.fasta`）。
- **字幕**：`第 n 步的 stdout，直接喂给第 n+1 步` → `中间结果从不落到磁盘` →
  `统计表，直接内嵌显示` → `PNG 绘图，同样直接内嵌显示`
- **声音**：预设与三步落下的 click、运行启动音、完成上扬和弦、结果揭示 tick。

### S6 · 核心能力三：GUI 背后没有黑箱（38.0 – 46.0s）

- **画面**：镜头下移到「等价命令行」条，逐 token 高亮
  `clean seqs --align 'F:\…\demo.fasta' | clean sites --char GAP --cutoff 0 | stats`，点「复制」。
  斜向擦除切到终端：命令**一次性粘贴**出现并高亮闪一下（粘贴不是逐字敲），回车后统计输出逐行流入，
  浮出 `✓ 与面板结果逐字一致 · 86 ms`。
  面板写出的是参数、终端需要程序名，故画面标注
  `面板里省略的是程序名：终端里每步前缀 goalign`，终端中的命令每步带 `goalign` 前缀。
- **字幕**：`等价命令行，始终可见` → `用界面搭的每一步，都能复制进终端原样跑`
- **声音**：复制 pop、粘贴 click、回车 thud、输出 tick 序列、完成和弦。

### S7 · 特性快切四连（46.0 – 54.0s）

- **版式**：四张卡共用一套栅格（1440×668，左右内边距 72）——
  顶部 kicker 胶囊 → 62px 标题 → 强调色分隔线 → 左栏视觉演示 + 右栏三条「粗体小标题 + 灰色说明」
  → 底部一条脚注带（左侧色条 + 一句硬信息 + 右端 `SeqPanel` 标记）→ 屏底主字幕。
- **画面**：每张 2s，卡间用**整卡左右滑动轮播**衔接（末 0.3s 当前卡左出、下一卡右入），
  两卡始终水平分离，既不闪黑也不会叠字：
  1. **下载即用** —— 左栏 .exe 文件卡 + 首次启动解出进度条 + 三枚标签
     （`Windows 10 / 11`、`WebView2 即可`、`Apache-2.0`）；右栏「单文件自包含 / 首次启动自动解出 /
     零运行库依赖」；脚注 `76 个可执行命令 · 42 个顶层命令组 · 开箱可用`；
  2. **双语界面** —— 左栏六行界面词中英对照表（随进度整体互换），右栏「运行时即时切换 /
     选择会被记住 / 命令名保持英文」；脚注 `界面文案双语 · 上游说明原文保留`；
  3. **三套主题** —— 左栏两张真实截图（`interface-en-light.png` / `interface-zh-dark.png`）
     带「浅色 / 深色」标签滑入，右栏「浅色 · 深色 / 跟随系统 / 原生标题栏一起变」；
  4. **通用反射引擎** —— 左栏 `goalign.exe` 面板与 `gotree.exe` 面板并列，中间箭头随进度点亮，
     右栏「反射引擎是通用的 / 工具包补齐缺口 / 换一个二进制」；
     脚注 `GoAlign · GoTree · 任意 cobra 二进制`。
- **字幕**：`免安装 · 下载即用` / `中文 · English 运行时切换` / `浅色 · 深色 · 跟随系统` /
  `一个面板，驱动任意 cobra 工具`
- **声音**：四拍节奏点，每拍一张卡。

### S8 · 尾板（54.0 – 60.0s）

- **画面**：粒子向心收束，`SeqPanel` 字标淡入升起（不再硬切），下方 tagline 与获取方式逐行淡入，
  最后 0.8s 淡出到黑。
- **字幕**：`SeqPanel` / `下载即用 · 没有黑箱` / `github.com/ZengZichao/SeqPanel-Windows` /
  `Apache License 2.0 · Windows 10 / 11 · 内置 GoAlign v0.4.1`
- **声音**：BGM 收束和弦 + 长混响尾音。

## 质检记录（v3 修复清单）

逐帧（1800 帧全扫描，0 运行时报错）与逐秒（`blackdetect` / `freezedetect` / `silencedetect` /
`astats` / 全解码完整性）两级检查后修复：

| 类别 | 问题 | 修复 |
|---|---|---|
| 画面 | 0–3.97s 被判黑屏：终端卡片过大、只有一行内容 | 卡片按内容收拢、加发光描边、补回滚历史 |
| 转场 | 10.87–12.53s 死场 1.67s | 光带提前至 10.55s 与 S2 交叠，加地平线光晕与火花 |
| 画面 | 42.5–44.27s 近黑 1.77s | 终端卡片收拢提亮，粘贴改为瞬间出现 + 高亮闪 |
| 转场 | 45.8 / 48 / 50 / 52s 卡间闪黑 | 先试交叉淡化，发现两卡文字会叠成乱码 |
| 文字 | 交叉淡化导致两张卡同屏、标题与字幕互相压字 | 改为整卡左右滑动的轮播，两卡始终水平分离 |
| 文字 | 特性卡字幕几乎全程不可见（alpha 包络被推到饱和后归零） | 字幕进度改随卡片生命周期 0→1，淡入淡出与滑动同步 |
| 画面 | 特性卡面板在轮播改造后完全不绘制（透明度包络返回 0） | 面板改为恒定不透明，进出场只靠位移 |
| 画面 | 热图卡片右下两行标注重叠成一片 | 尺寸标注移到网格左端，与「内嵌显示」分开 |
| 画面 | S4 状态栏用成功绿表示缓存命中 | 恢复为常规灰色，绿色只留给运行成功 |
| 画面 | 8.4–9.2s、44.5–45.4s 仍有 0.8s+ 静止 | 痛点卡加代码行扫描高光，终端段加缓慢推近 |
| 音频 | 结果揭示 tick 越过 35.6s 与预设点击打架 | 收敛到 8 下，止于 35.1s |
| 画面 | 18.03–20.93s 冻结 2.9s | 命令树流入放慢填满该段，加「反射中」状态进度 |
| 画面 | 演示段多处 1s+ 静止 | 演示全程加持续微幅运镜 |
| 事实 | 把 `draw png` 结果接在 `stats` 之后 | `stats` 是终止步，图形改由独立单步链产出 |
| 事实 | `draw png` 画成系统发育树 | 它是比对热图，重绘为 8×60 一位点一像素 |
| 事实 | 暗示等价命令行可原样粘进终端运行 | 终端形式每步补 `goalign` 前缀并加说明 |
| 事实 | 预设链缺 `--char GAP` | 按文档补回，表单同步增加该开关 |
| 文字 | 命令说明被列边界硬切 | 按列宽截断并加 `…` |
| 文字 | 中英字幕错配、`.exe` 命名不符、尾板字标硬切入 | 逐条改正 |
| 文字 | 长命令行超出终端卡片宽度 | 字号收小并加宽卡片，消除溢出 |
| 音频 | 音效时点与画面节拍错位 | 全部按新节拍重对；粘贴处不再用打字音 |
| 文字 | 管道标注 stdout / stdin 压在步骤序号上，序号被遮成乱码 | 删除冗余标注（字幕已说明），只保留流动管道 |
| 画面 | 推近镜头里相邻列被裁成半截词，读起来像渲染故障 | 加聚焦暗角，压住焦点外的溢出文字 |
| 排版 | 48–54s 特性卡：kicker 压标题、右半屏大片空白、术语表像裸表格 | 四卡统一栅格（标题 / 分隔线 / 左视觉 / 右三条要点 / 脚注带） |
| 排版 | 双语卡第 6 行「运行 / Run」溢出面板底边 | 行高按面板高度自适应，并对面板做裁剪 |
| 音频 | 转场 riser、whoosh、镲、hat、军鼓、点击全靠宽带噪声，听感像「蒸汽 / 嘶声」 | 全部改为谐波合成：音高上扫 + 渐密颤音、金属泛音铃、调谐 rimshot、正弦 ping |
| 音频 | 换掉噪声后动态拉太开（LRA 17.9 LU），前 11s 近乎没声 | 铺底抬到 0.46、开场加心跳底鼓与闭镲、breakdown 少压一点 |

| 交付 | 多余的 `.srt` 字幕文件 | 按要求删除，只保留画面内字幕 |
